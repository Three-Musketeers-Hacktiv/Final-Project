# Lingkup permainan Bastionfall

Pemain mendaftar atau login, memilih Easy, Normal, atau Hard, lalu mempertahankan kota selama 100 hari. Run aktif dapat dilanjutkan dari save MongoDB.

- Persiapan mencakup upgrade tembok, pasukan, kota, dan repair. Pemain dapat menyelesaikan satu dari empat aksi itu per hari persiapan.
- Event menggabungkan pilihan dan efek terpercaya dari engine dengan narasi Gemini atau fallback. Keputusan pemain dapat memicu konsekuensi.
- Sepuluh wave diselesaikan melalui battle otomatis dengan laporan ronde. Wave pertama sampai kesembilan menawarkan reward. Wave terakhir menentukan kemenangan kampanye.

[Aturan permainan](PRD.md) menjelaskan angka dan transisi. [Panduan aplikasi](app/README.md) mencakup setup lokal.
