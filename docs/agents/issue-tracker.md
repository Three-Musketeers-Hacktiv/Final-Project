# Issue Tracker: Markdown Lokal

- Setiap fitur memiliki direktori `.scratch/<nama-fitur>/`.
- Spesifikasi disimpan sebagai `spec.md` dalam direktori fitur.
- Setiap tiket memiliki file sendiri di `issues/<NN>-<nama-tiket>.md`, dimulai dari `01`.
- Status dicatat sebagai `Status:` di bagian atas file.
- Komentar ditambahkan di bagian bawah dengan judul `## Comments`.
- Instruksi “publish to the issue tracker” berarti membuat atau memperbarui file lokal tersebut.
- Tidak menerbitkan GitHub Issue.
