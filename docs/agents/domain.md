# Dokumentasi Domain

Proyek menggunakan satu konteks.

Sebelum mengeksplorasi area terkait, baca `GLOSSARY.md` dan keputusan arsitektur di `docs/adr/` jika tersedia.

Jika belum tersedia, lanjutkan tanpa mewajibkan pembuatannya. Gunakan istilah glossary secara konsisten. Jika usulan bertentangan dengan keputusan arsitektur yang ada, jelaskan konflik tersebut.
